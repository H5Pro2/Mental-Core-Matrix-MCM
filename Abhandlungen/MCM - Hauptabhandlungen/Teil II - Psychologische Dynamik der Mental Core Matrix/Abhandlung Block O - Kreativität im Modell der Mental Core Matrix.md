# Abhandlung Block O - Kreativität im Modell der Mental Core Matrix


Block O
Kreativität im Modell der Mental Core Matrix
Eine mögliche strukturelle Perspektive auf kreative Prozesse

Kreativität wird in verschiedenen Disziplinen unterschiedlich beschrieben.
In der Psychologie wird sie häufig mit Problemlösefähigkeit, Vorstellungskraft oder
künstlerischer Begabung verbunden.
Im Rahmen der Mental Core Matrix kann eine ergänzende Perspektive formuliert werden.
Dabei wird angenommen, dass kreative Prozesse auch als dynamische Zustände innerhalb
komplexer Systeme verstanden werden können.

Aus dieser Perspektive erscheint Kreativität nicht nur als individuelle Fähigkeit, sondern als ein
bestimmter Zustand eines Systems, in dem Variation und Stabilisierung in einem besonderen
Verhältnis stehen.

1. Rolle der Varianz
Im Modell der MCM spielt Varianz eine zentrale Rolle.
Varianz beschreibt die Bandbreite möglicher Zustände innerhalb eines Systems.
Eine erhöhte Varianz kann dazu beitragen, dass neue Kombinationen von Ideen,
Wahrnehmungen oder Handlungen entstehen.
Wenn diese Variationen gleichzeitig durch stabilisierende Prozesse reguliert werden, können
daraus neue Muster hervorgehen.
In diesem Sinne könnte Kreativität als ein Zustand interpretiert werden, in dem Variabilität
vorhanden ist, ohne dass das System vollständig instabil wird.

2. Zwischen Stabilität und Instabilität
Kreative Prozesse scheinen häufig in einem Bereich zu entstehen, der zwischen starker Ordnung
und vollständiger Unordnung liegt.
Zu starke Stabilität kann dazu führen, dass bestehende Muster unverändert bleiben.
Zu große Instabilität kann dagegen dazu führen, dass keine konsistenten neuen Muster
entstehen.
Kreativität könnte daher in einem Bereich auftreten, in dem Systeme gleichzeitig flexibel und
stabil genug sind, um neue Strukturen zu bilden.

3. Emotionale Sensibilität


Viele kreative Menschen berichten von erhöhter emotionaler Sensibilität oder intensiver
Wahrnehmung.
Dies könnte teilweise damit zusammenhängen, dass kreative Prozesse häufig mit erhöhter
Variabilität und schnellen Wechseln mentaler Zustände verbunden sind.
Solche Zustände können sowohl produktive als auch belastende Aspekte haben.

4. Rolle stabiler Zustände
Obwohl Kreativität mit Variabilität verbunden ist, benötigen kreative Prozesse auch Phasen
relativer Stabilität.
Solche Phasen können beispielsweise auftreten bei:
• konzentrierter Aufmerksamkeit
• ruhiger Reflexion
• strukturierter Arbeit an Ideen.
Im Rahmen der MCM könnten solche Zustände als Phasen verstanden werden, in denen neue
Muster stabilisiert und integriert werden.

5. Kreativität und Lebensverläufe
Historische Beispiele zeigen, dass viele kreative Persönlichkeiten ungewöhnliche oder instabile
Lebensverläufe hatten.
Dies könnte teilweise damit zusammenhängen, dass kreative Prozesse mit hoher Variabilität und
intensiver Auseinandersetzung mit neuen Ideen verbunden sind.
Solche Dynamiken können sowohl Innovation als auch persönliche Herausforderungen mit sich
bringen.

6. Verbindung von Energie und Information
In komplexen Systemen können neue Informationen entstehen, wenn unterschiedliche
Zustände miteinander kombiniert oder reorganisiert werden.
Im Rahmen der MCM könnte Kreativität als ein Prozess interpretiert werden, in dem Variationen
innerhalb eines Systems zu neuen strukturellen Kombinationen führen.
Diese Kombinationen können anschließend stabilisiert und in bestehende Strukturen integriert
werden.

7. Emergenz neuer Muster
Ein wichtiger Aspekt kreativer Prozesse besteht darin, dass neue Ideen oder Lösungen oft
unerwartet entstehen.


In dynamischen Systemen spricht man in solchen Fällen häufig von Emergenz.
Das bedeutet, dass neue Muster aus der Interaktion verschiedener Elemente entstehen können,
ohne dass sie direkt geplant wurden.

8. Plötzliche Einsichten
Viele Menschen berichten, dass kreative Ideen plötzlich auftreten.
Solche sogenannten „Aha-Momente“ könnten darauf hinweisen, dass ein System zuvor
verschiedene Möglichkeiten verarbeitet hat und schließlich eine neue stabile Konfiguration
entsteht.
Der Moment der Einsicht wäre dann der Zeitpunkt, an dem diese neue Konfiguration bewusst
wahrgenommen wird.

9. Kreative Blockaden
Kreative Blockaden treten häufig auf, wenn Systeme entweder zu stark stabilisiert oder durch
äußere Belastungen eingeschränkt sind.
In solchen Situationen kann die Variabilität eingeschränkt sein, sodass neue Muster schwer
entstehen.
Viele kreative Prozesse profitieren daher von Bedingungen, die sowohl Flexibilität als auch
Stabilität ermöglichen.

10. Schlussfolgerung
Im Modell der Mental Core Matrix kann Kreativität als ein dynamischer Zustand interpretiert
werden, in dem Variabilität und Stabilisierung in einem ausgewogenen Verhältnis stehen.
Diese Perspektive ersetzt keine etablierten psychologischen oder neurobiologischen Modelle
der Kreativität.
Sie kann jedoch als ergänzender struktureller Rahmen dienen, um kreative Prozesse aus Sicht
komplexer Systeme zu betrachten.
Kreativität erscheint dabei nicht nur als individuelles Talent, sondern als Ausdruck bestimmter
dynamischer Zustände innerhalb eines Systems.
