# A - Psychologische Mental Core Matrix


Dokument A
Psychologische Mental Core Matrix (MCM)
Energetisches Feldmodell mentaler Zustände
(17 Archetypen, vier Gruppen, vier Übergänge, Zentrum)

1. Einordnung
Im Rahmen dieses hypothetischen Modells kann die Psychologische Mental Core Matrix
(MCM) als energetisches Modell zur Beschreibung mentaler, emotionaler und kognitiver
Zustände betrachtet werden. Im Modell wird der innere Erlebensraum nicht als statische
Typologie verstanden, sondern als kontinuierliches Energie- und Zustandsfeld
modelliert.
Mentale Aktivität kann innerhalb einer eindimensionalen Energiedimension modelliert
werden.
−3 ≤ 𝐸 ≤ +3
verortet.
In diesem Kontinuum liegen energetisch charakteristische Muster, die als Archetypen
beschrieben werden.
Das Modell umfasst:
• vier Hauptgruppen (G1–G4)
• ein Zentrum (Z)
• vier Übergangszonen (U1–U4)
• zwölf Grundarchetypen (A1–A12)
• vier Übergangsarchetypen
• insgesamt 17 eindeutige Zustandsformen
Die psychologische MCM dient der Modellierung mentaler Dynamik, sozialer
Wechselwirkung und KI-basierter Verhaltenslogik.

2. Energetischer Raum
Der Energieraum kann im Modell als Grundlage der Zustandsbeschreibung interpretiert
werden. Er reicht von starker negativer Überladung bis zu starker positiver Hochladung.
Bedeutung der Energiewerte:
• −3: maximale negative Überladung
• 0: neutraler Kernpunkt
• +3: maximale positive Hochladung
Im Modell wird Energie als kontinuierliche Größe angenommen.
Die Archetypen können als diskrete Muster interpretiert werden, die bevorzugt in
bestimmten energetischen Bereichen auftreten.


Typische energetische Zonen:
• G1: −3 bis −1
• G2: −1 bis +1
• Zentrum: 0
• G3: +1 bis +2
• G4: +2 bis +3

3. Zentrum (Z)
Das Zentrum kann im Modell als Nullpunkt der Energiedimension interpretiert werden.
Im Modell wird es nicht als Persönlichkeitstyp verstanden, sondern als systemischer
Zustand relativer Ausgewogenheit.
Eigenschaften des Zentrums:
• Energetische Neutralität
• Selbstreflexion
• Regulation
• emotionale Ausgeglichenheit
• Vermittlung zwischen allen Gruppen
Im Rahmen des Modells kann das Zentrum eine Rolle bei Rückkehr, Integration und
Stabilisierung von Zustandsdynamiken spielen.

4. Die vier Hauptgruppen (G1–G4)
4.1 Gruppe G1 – Äußerste linke Zone
Energie: −3 bis −1
Grundthema: emotionale Überladung, Abwehr, Stressreaktionen
• A1 (ca. −3): Aggression
Explosive Negativeindynamik, impulsive Reaktivität
• A2 (ca. −2): Misstrauen
Alarmbereitschaft, Verdacht, distanzierte Schutzreaktionen
• A3 (ca. −1): Rückzug
Absenkung der Aktivität, Isolation, Abschottung

4.2 Gruppe G2 – Linke mittlere Zone
Energie: −1 bis +1
Grundthema: Unsicherheit, Klärung, beginnende Neuordnung
• A4 (ca. −1): Zweifel
Hinterfragen, Vorsicht, innere Ambivalenz


• A5 (ca. 0): Reflexion
Innenschau, Analyse, gedankliche Organisation
• A6 (ca. +1): Diskussion
Aktive kommunikative Klärung, Austausch, Strukturierung durch Sprache

4.3 Zentrum (Z)
Energie: 0
Grundthema: Ausgleich, Regulation, Selbstreflexion
Z ermöglicht die Neutralisierung polarer Zustände und stellt die innere Baseline her.

4.4 Gruppe G3 – Rechte mittlere Zone
Energie: +1 bis +2
Grundthema: geordnete Aktivierung, strukturierte Zuwendung, analytische Orientierung
• A7 (ca. +1): Belehrung
Strukturiertes Weitergeben, Einordnen, Erklären
• A8 (ca. +2): Zuwendung
Verbindende, tragende, unterstützende Haltung
• A9 (ca. +2): Analyse
Präzise Durchdringung, detaillierte Strukturierung, rationale Klarheit

4.5 Gruppe G4 – Äußerste rechte Zone
Energie: +2 bis +3
Grundthema: rationale Hochladung, mentale Expansion, distanzierte Klarheit
• A10 (ca. +2): Rationalität
Logik, Objektivität, zielorientiertes Denken
• A11 (ca. +3): Offenheit
Weites Wahrnehmungsfeld, mentale Durchlässigkeit
• A12 (ca. +3): Kognitive Neutralität
Distanz, Beobachtung, hohe Klarheit ohne emotionale Bindung

Daraus kann sich im Modell folgende energetische Achse ergeben:
-3, -2, -1, -1, 0, +1, +1, +2, +2, +2, +3, +3

5. Übergangszonen (U1–U4)


Übergangszonen können im Modell dort auftreten, wo zwei energetische Felder
gleichzeitig aktiv sind. Im Modell werden sie nicht als Mischtypen verstanden, sondern
als eigenständige dynamische Muster interpretiert.
U1 – G1 ↔ G2
Energie: −1.5 bis −0.5
Thema: Irritation, erste Klärungsbewegung
U2 – G2 ↔ Zentrum
Energie: −0.2 bis +0.2
Thema: Beruhigung, Entladung, Meta-Analyse
U3 – Zentrum ↔ G3
Energie: +0.2 bis +0.8
Thema: geordnete Aktivierung, Öffnung
U4 – G3 ↔ G4
Energie: +1.8 bis +2.4
Thema: rationale Expansion, mentale Beschleunigung

7. Dynamik der psychologischen MCM
Die MCM kann als Modell eines dynamischen Bewegungsraums interpretiert werden,
nicht als statische Kategorienstruktur.
Typischer Zyklus:
Chaos → Suche → Ordnung → Stabilität → Zentrum → erneuter Übergang
Regeln der Dynamik:
• Energie bestimmt Intensität und Richtung
• Archetypen bestimmen die qualitative Ausprägung
• Übergangszustände steuern Flexibilität oder Instabilität
• das Zentrum wirkt ausgleichend und stabilisierend

8. Anwendung in Psychologie, KI und Simulation
Die psychologische MCM kann als strukturiertes energetisches Zustandsmodell
verwendet werden für:
• mentale Zustandsverläufe
• Verhalten und Reaktionsmuster
• soziale Dynamiken
• Entscheidungslogiken
• KI-basierte Agentensimulation
• energetische Interaktionsmodelle
Das Modell eröffnet die Möglichkeit:
• Klassifikation innerer Zustände
• Analyse von Spannungen, Übergängen und Polarisierungen
• Modellierung von Selbstregulation
• dynamische Simulation mentaler Prozesse
