Dokument B
Reine MCM
Fundamentales energetisches Kontinuum
(Archetypenfreie Ebene, Grundlage von MCM-Infinity)

1. Einordnung
Im Rahmen dieses hypothetischen Modells kann die Reine MCM als nicht-
psychologische, nicht-interpretative Grundform der Mental Core Matrix betrachtet
werden. Im Modell wird der Energieraum unabhängig von möglichen psychologischen
Interpretationen betrachtet.
Während die psychologische MCM Archetypen nutzt, um Energie in menschlicher
Sprache darzustellen, verzichtet die reine MCM vollständig auf:
• Kategorien
• mentale Typen
• semantische Muster
• gruppenbasierte Zuordnung
• symbolische Strukturierung
Die reine MCM kann als Modell einer grundlegenden Energiestruktur verstanden werden,
aus der emergente Muster entstehen können.

2. Energieraum und Strukturprinzip
Die reine MCM beruht auf einem einzigen Kontinuum:
−3 ≤ 𝐸 ≤ +3
Dieses Kontinuum kann im Modell durch drei grundlegende Eigenschaften beschrieben
werden.
1. Zwei Pole
ein negativer und ein positiver Extrembereich
2. Einen zentralen Nullpunkt
als energetischer Attraktor, Ausgleichs- und Umkehrpunkt
3. Ein kontinuierliches Fließverhalten
zwischen den Polen und dem Zentrum, ohne diskrete Zustände
Im Modell werden keine Archetypen angenommen.
Das Modell betrachtet ausschließlich Energie in dynamischer Bewegung.

3. Was Energie in der reinen MCM ist


Energie im Sinne der reinen MCM hat folgende Merkmale:
• kontinuierlich
• formfrei
• typfrei
• nicht kategorisiert
• nicht interpretiert
• ohne semantische Bedeutung
Im Modell werden Archetypen nicht als Eigenschaft der Energie angenommen.
Archetypen können innerhalb dieses Modells als menschliche Interpretationen
energetischer Muster verstanden werden.
Im Modell werden dagegen folgende dynamische Eigenschaften betrachtet:
• Fluss
• Gradient
• Attraktion
• Abstoßung
• Verdichtung
• Entladung
• Stabilisierung
• Übergänge
• emergente Muster
• Symmetriebrüche
• Attraktoren

4. Hauptdynamiken der reinen MCM
4.1 Kontinuierlicher Fluss
Im Modell kann Energie als kontinuierlich zwischen den Polen beweglich interpretiert
werden. von hoher Ladung in Richtung Zentrum und umgekehrt.
4.2 Attraktion zum Zentrum
Der Nullpunkt kann im Modell als systemischer Attraktor interpretiert werden.
Im Modell kann er als Zustand relativer Balance interpretiert werden.
4.3 Polarität
Die Pole können als energetische Extrembereiche interpretiert werden.
Sie können Spannungsgradienten erzeugen.
4.4 Übergänge statt Kategorien
In der reinen MCM gibt es keine Gruppen (G1–G4) und keine Übergangstypen (U1–U4).
Es gibt nur kontinuierliche Übergänge, die ohne Diskretisierung ablaufen.
4.5 Emergenz


Muster entstehen durch lokale Wechselwirkungen, nicht durch feste Zuordnungen.
Die Simulation legt nahe, dass Strukturen, Cluster und Stabilitätsmuster aus lokalen
Wechselwirkungen entstehen können.

5. Der Nullpunkt als zentraler Attraktor
Der Nullpunkt wird im Modell nicht als psychologisches Zentrum interpretiert.
Er besitzt:
• minimale Potenzialspannung
• maximale Balance
• maximale Symmetrie
• geringste strukturelle Schieflage
• höchste Wahrscheinlichkeit als Ruhe- oder Kreuzungspunkt
Im Modell können sich Muster in der Nähe dieses Nullpunkts bilden oder stabilisieren.

6. Archetypen existieren hier nicht
Eine mögliche Interpretation innerhalb dieses Modells:
Archetypen werden nicht als Eigenschaft der Energie angenommen,
sondern können als Ergebnis kognitiver Interpretation verstanden werden.
Die 17 Archetypen sind somit:
• Interpretationen
• symbolische Verdichtungen
• menschliche Ordnungsschemata
• semantische Projektionen
Die reine MCM kann als energetische Grundlage interpretiert werden.

Die reine MCM kann als fundamentale energetische Struktur interpretiert werden.

Sie umfasst:
