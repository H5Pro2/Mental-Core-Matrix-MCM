# MCM-Begriffsbrücke und wissenschaftlicher Anschluss

## Zweck

Dieses Dokument dient als Übersetzungsschicht zwischen der internen Sprache der Mental Core Matrix und einer anschlussfähigeren Außen-Sprache. Es soll die MCM nicht glätten oder in ein fremdes Fachgebiet pressen, sondern lesbarer machen.

Die MCM bleibt ein eigenständiger Modellrahmen. Gleichzeitig soll klarer werden, welche Aussagen als Hypothese, Metapher, Simulation, Beobachtung oder möglicher Beleg zu lesen sind.

## Grundprinzip

Die MCM soll zweisprachig dokumentiert werden:

- **MCM-Sprache** beschreibt die innere Logik des Modells.
- **Außen-Sprache** beschreibt, woran ein Leser aus Wissenschaft, Informatik, Psychologie oder Mathematik ungefähr anknüpfen kann.

Die Außen-Sprache ist keine Gleichsetzung. Sie ist eine Orientierungshilfe.

## Statusmarker für Aussagen

Jede zentrale Aussage der MCM sollte möglichst mit einem Statusmarker gelesen oder ergänzt werden:

| Marker | Bedeutung |
| --- | --- |
| **Hypothese** | Eine mögliche Modellannahme, die noch geprüft oder präzisiert werden muss. |
| **Metapher** | Ein Bild, das Struktur verständlich macht, aber kein formaler Beweis ist. |
| **Beobachtung** | Eine wiederkehrende Wahrnehmung, ein Muster oder ein Ergebnis aus Dokumentation, Simulation oder Analyse. |
| **Simulation** | Ein künstlich erzeugter Modellversuch, der Dynamiken sichtbar macht, aber noch keine reale Gültigkeit beweist. |
| **Belegkandidat** | Ein Hinweis, der die Modellrichtung stützt, aber noch nicht als wissenschaftlicher Beweis gilt. |
| **Beweis** | Nur verwenden, wenn Methode, Daten, Prüfung und Gegenprüfung ausreichend dokumentiert sind. |

## Begriffsbrücke

| MCM-Sprache | Außen-Sprache / Anschlussbegriff | Hinweis |
| --- | --- | --- |
| MCM-Feld | Zustandsraum, Spannungsraum, relationaler Modellraum | Kein physikalisches Feld im engeren Sinn, solange keine formale physikalische Definition vorliegt. |
| Zentrum | Referenzzustand, Gleichgewichtspunkt, stabilisierender Bezug | Kann als Nullpunkt oder regulativer Anker gelesen werden. |
| Abweichung | Auslenkung, Störung, Zustandsverschiebung | Beschreibt Bewegung weg vom Zentrum, nicht automatisch Fehler oder Negativität. |
| Varianz | Möglichkeitsraum, Zustandsstreuung, Suchraum | Bereich, in dem neue Muster oder Reaktionen entstehen können. |
| Rückführung | Rückkopplung, Regulation, Re-Integration | Prozess, der Spannung wieder ordnet oder neu stabilisiert. |
| Feldzeit | zeitliche Tiefenstruktur, Nachwirkzeit, Integrationsdauer | MCM-interner Begriff für die zeitliche Qualität eines Feldzustands. |
| Nachhall | Persistenz, Erinnerungsspur, verzögerte Wirkung | Beschreibt, dass ein Impuls im Modell nicht sofort verschwindet. |
| Bedeutungsinsel | semantischer Cluster, stabilisierte Bedeutungseinheit | Eine lokale Verdichtung von Bedeutung, noch kein Beweis für echte Kognition. |
| DIO | digitaler Organismus, agentenartiges System, künstlicher Modellträger | Interner Begriff für ein System mit eigener Wahrnehmungs- und Ordnungslogik. |
| Reine MCM | abstrakte Struktur- oder Energieebene | Archetypenfreie Ebene des Modells; nicht automatisch physikalische Energie. |
| Psychologische MCM | Interpretationsebene, psychodynamische Modellprojektion | Übertragung der Struktur auf Verhalten, Emotion und Selbstregulation. |
| Emergenz | Musterbildung, Selbstorganisation, makroskopische Ordnung | Muss je nach Kontext durch Simulation oder Beobachtung konkretisiert werden. |
| Attraktor | stabilisierende Zustandsform, Musteranziehung | Anschluss an dynamische Systeme, aber nur dann formal, wenn mathematisch definiert. |

## Wissenschaftliche Anschlussfähigkeit

Für Außenstehende sollte die MCM nicht als fertige Theorie von allem auftreten. Anschlussfähiger ist folgende Form:

> Die MCM ist ein eigenständiger Modellrahmen zur Beschreibung von Zentrum, Abweichung, Varianz und Rückführung in dynamischen Systemen. Sie nutzt eigene Begriffe, kann aber teilweise an Zustandsräume, Attraktoren, Rückkopplung, Selbstorganisation, semantische Cluster und agentenbasierte Simulationen angeschlossen werden.

Damit bleibt die MCM offen für Prüfung, ohne ihre eigene Sprache zu verlieren.

## Grenzen

Die MCM sollte klar trennen:

- Was ist interne Modelllogik?
- Was ist metaphorische Beschreibung?
- Was wurde simuliert?
- Was wurde beobachtet?
- Was ist nur ein Vergleich zu bestehenden Forschungsfeldern?
- Was wäre tatsächlich prüfbar?

Besonders wichtig: Begriffe aus Physik, Psychologie, Mathematik oder Informatik sollten nicht so verwendet werden, als wären sie bereits fachwissenschaftlich bewiesen, wenn sie innerhalb der MCM eine eigene Bedeutung tragen.

## Schreibregel für neue Texte

Neue MCM-Texte sollten nach Möglichkeit diese kleine Prüfstruktur enthalten:

```text
MCM-Begriff:
Außen-Anschluss:
Status:
Prüfbarkeit:
Grenze:
```

Beispiel:

```text
MCM-Begriff: Feldzeit
Außen-Anschluss: zeitliche Persistenz, Integrationsdauer, Nachwirkzeit eines Zustands
Status: Hypothese / Modellbegriff
Prüfbarkeit: über Simulationen, Verlaufsdaten oder wiederkehrende Muster prüfbar
Grenze: kein etablierter physikalischer Zeitbegriff
```

## Kurzfassung

Die MCM darf eine eigene Sprache haben. Damit sie aber von außen verstanden und geprüft werden kann, braucht sie eine zweite Ebene: klare Übersetzung, klare Statusmarker und klare Grenzen zwischen Hypothese, Metapher, Simulation, Beobachtung und Beweis.
